# Bachelor

Planning site for Don's bachelor ski trip: Sat Feb 20 – Sun Feb 28, 2027, 6 people, 3 days of skiing plus a few days in a nearby city.

It compares four options, each with per-person costs, where to stay (with photos and links), car rental and day-to-day transport, ski days, city activities, food, and a day-by-day plan:

- Whistler + Vancouver
- Banff + Calgary
- Mayrhofen + Munich
- Barcelona + Andorra

## Where to see it

- **claude.ai version (live voting):** https://claude.ai/artifact/X6CbmKDP5bTXR9qdmUgZAN. Votes and suggestions are stored there.
- **GitHub Pages version:** `index.html` in this repo. Friends can browse everything and send their vote as a link, which the organizer opens on the claude.ai version to record it.

## Files

| File | What it is |
|---|---|
| `ski-trip-breakdown.html` | Page source published to claude.ai. It has no `<html>`/`<head>` because the claude.ai viewer adds them. |
| `index.html` | Standalone copy for GitHub Pages, generated by `build.py`. |
| `build.py` | Run `python3 build.py` after editing the page source to regenerate `index.html`. |
| `img/` | Destination photos (Wikimedia Commons) and `img/stay/` lodging photos (from each property's website). |
| `trip-brief.md` | Trip parameters the research agent reads first. |
| `.claude/agents/ski-trip-planner.md` | Claude Code agent used to research and price the options. |

## Photos

Destination photos come from Wikimedia Commons under the licenses listed on the site's Plan page. Lodging photos come from each property's own website, belong to those properties, and link back to them.
